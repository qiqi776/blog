本页详细说明 zfeed 微服务中使用的基础设施包。这些包提供基于 GORM 的标准化 MySQL 连接、基于环境变量的配置加载、通过 XXL-JOB 实现的分布式任务调度，以及通用工具函数。

ORM 与数据库连接 ​

orm 包为所有 RPC 服务提供统一的 GORM 初始化方式。它会强制设置连接池限制，配置与 go-zero 的 logx 集成的自定义 logger，并自动注册用于性能监控的 observer 插件。

实现细节 ​

核心初始化函数 orm.NewMysql orm/orm.go#64-114 会执行以下步骤：

  1. 连接池配置：如果未显式提供，则为 MaxIdleConns（10）、MaxOpenConns（100）和 MaxLifetime（3600s）设置默认值 orm/orm.go#16-20
  2. 自定义 Logger：挂载 observerLogger orm/orm.go#31-62，通过 logx.WithContext(ctx) 将 GORM 内部日志重定向到服务的结构化日志。
  3. 插件注册：自动安装 ObserverPlugin orm/orm.go#109-111。该插件负责发出指标，并记录超过 SlowThreshold（默认 200ms）的慢查询 orm/orm.go#19

环境与配置加载 ​

zfeed 使用混合配置方式。服务专属设置定义在 YAML 文件中，例如 user.yaml；基础设施坐标，包括 IP、端口和凭据，则通过环境变量注入。这一过程由 go-zero 的 conf.Load 工具配合 conf.UseEnv() 选项完成。

环境变量映射 ​

系统依赖 .env.local 文件，或生产环境中的容器环境变量，来填充 YAML 文件中的模板。

XXL-JOB 分布式任务调度 ​

xxljob 包会在配置中被引用，用于启用分布式 cron 任务，例如 content-rpc 服务中的热门内容排行更新。

配置 ​

执行器通过环境变量配置，这些变量定义 admin 地址以及执行器自身的注册信息：

  • XXL_JOB_ADMIN_ADDR：XXL-JOB 中央管理控制台的 URL app/rpc/content/internal/config/config_env_test.go#22
  • XXL_EXECUTOR_IP / XXL_EXECUTOR_PORT：admin 控制台联系 RPC 服务以触发任务的地址 app/rpc/content/internal/config/config_env_test.go#25-26
  • XXL_JOB_ACCESS_TOKEN：admin 与 executor 之间通信使用的安全 token app/rpc/content/internal/config/config_env_test.go#27

来源：app/rpc/content/internal/config/config_env_test.go#22-27 .env.local.example#27-32

工具包与常量 ​

通用工具和共享配置分布在 pkg 目录以及特定辅助文件中。

Redis 与连接默认值 ​

系统使用标准化连接设置，以保证高负载下的稳定性：

  • Redis：通过 YAML 中的 RedisConfig 配置，通常使用 node 类型来表示单实例或标准集群 app/rpc/user/etc/user.yaml#52-55
  • MySQL 超时：ORM 层默认使用 200ms 慢查询阈值 orm/orm.go#19

日志与遥测 ​

所有服务共享标准日志格式：

  • Mode：file，输出到磁盘供 Logstash 收集 app/front/etc/front-api.yaml#16
  • Encoding：json，便于结构化解析 app/front/etc/front-api.yaml#17
  • Rotation：daily，并设置 KeepDays: 1 app/front/etc/front-api.yaml#24-28
